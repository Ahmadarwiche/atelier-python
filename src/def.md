# Qu’est-ce que Python ?

Le langage de programmation **Python** a été créé en 1989 par **Guido van Rossum**, aux Pays-Bas.  
Le nom *Python* vient d’un hommage à la série télévisée *Monty Python’s Flying Circus* dont G. van Rossum est fan.  
La première version publique de ce langage a été publiée en 1991.

La dernière version de Python est la **version 3**. Plus précisément, la version **3.11** a été publiée en octobre 2022.  
La version 2 de Python est obsolète et n’est plus maintenue, évitez de l’utiliser.

La **Python Software Foundation** est l’association qui organise le développement de Python et anime la communauté de développeurs et d’utilisateurs.

## Caractéristiques de Python

Python présente de nombreuses caractéristiques intéressantes :

- ✅ **Multiplateforme** : fonctionne sur Windows, Mac OS X, Linux, Android, iOS, Raspberry Pi, supercalculateurs…
- 💸 **Gratuit** : peut être installé librement sur n’importe quel appareil
- 🧠 **Langage de haut niveau** : facile à apprendre sans connaître le fonctionnement interne d’un ordinateur
- ▶️ **Langage interprété** : pas besoin de compilation, contrairement au C ou C++
- 🧱 **Orienté objet** : permet de concevoir des entités proches du monde réel
- ✨ **Facile à prendre en main**
- 🌍 **Le langage de programmation le plus utilisé au monde**

Toutes ces caractéristiques font que Python est désormais enseigné dans de nombreuses formations, du lycée à l’enseignement supérieur.
